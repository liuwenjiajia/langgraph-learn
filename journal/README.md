# 学习日志

记录每日学习内容，配合 [docs/AI智能体研发学习蓝图-6个月.md](../docs/AI智能体研发学习蓝图-6个月.md) 使用。

## 目录结构

```
journal/
├── README.md          本说明
├── template.md         每日日志模板
├── 2026-09/            按年月分目录
│   ├── 2026-09-11.md   每天一个文档
│   └── ...
└── 2026-10/
    └── ...
```

## 使用方式

1. 新的一天开始学习前，复制 `template.md` 到当月目录下，文件名为当天日期 `YYYY-MM-DD.md`。
2. 当月目录不存在时新建，格式为 `YYYY-MM`。
